# Tiny Farm Empire — дорожная карта

> Idle Arcade Tycoon про уютную low-poly ферму. Next.js + React Three Fiber.
> Детальный дизайн механик и чисел — в [docs/GDD.md](docs/GDD.md).

## 1. Видение

Игрок бегает маленьким фермером по красочной миниатюрной ферме, собирает урожай
в огромную стопку за спиной, загружает машины, продаёт продукцию и шаг за шагом
превращает пустой участок в шумный автоматизированный комплекс.

### Столпы дизайна

1. **Всё происходит на карте.** Покупка — это площадка на земле, на которую нужно
   встать. Улучшение машины — площадка рядом с машиной. Меню — только там, где без
   него никак (прокачка фермера в доме, настройки).
2. **Каждое действие приятно.** Растения пружинят, предметы летят по дуге, стопка
   качается, монеты звенят, здания вырастают из земли с подскоком.
3. **Видимый рост.** Ферма с каждой покупкой становится шире, плотнее и оживлённее:
   больше полей, машин, работников, животных и грузовиков.
4. **Ручной труд → автоматизация.** Сначала всё делает игрок; потом каждый ручной
   процесс можно поручить работнику — и смотреть, как он работает.
5. **Простота.** Никакой сложной стратегии. Понятно с первой секунды без текста.

## 2. Технологии и архитектура

| Слой | Решение | Почему |
|---|---|---|
| Фреймворк | Next.js 16 (App Router), TypeScript | требование; одна страница, клиентский рендер игры |
| 3D | three.js 0.186 + @react-three/fiber 9 | декларативная сцена + полный доступ к three |
| Состояние UI | Zustand 5 | лёгкий стор для HUD, без лишних ререндеров |
| Логика | чистый TypeScript-движок `src/game` | тестируемо, не зависит от React, можно гонять бота-симулятора |
| Ассеты | процедурные low-poly модели из примитивов, канвас-текстуры | ноль внешних файлов, мгновенная загрузка |
| Звук | синтез через WebAudio | ноль файлов, мгновенный отклик |
| Тесты | Vitest | юнит-тесты движка + бот-симуляция баланса |
| Сохранения | localStorage + версия + миграции | офлайн-прогресс, автосейв |

### Поток данных

```
 Ввод (клавиатура / джойстик)
        │
        ▼
 Game (src/game/engine) ── tick(dt) в useFrame ──► мутирует GameState
        │                                            │
        │ события (продажа, покупка, звук, тост)     │ читается каждый кадр
        ▼                                            ▼
 EventBus ─► audio / UI-store (Zustand)        R3F-рендереры (refs, instancing)
```

* Горячий цикл (позиции, стопки, рост растений) **не проходит через React** —
  рендереры читают состояние движка в `useFrame` и пишут матрицы инстансов.
* React перерисовывает сцену только при структурных изменениях (открыта постройка,
  нанят работник) — через счётчик `structureVersion`.
* Мир = статичный макет (`data/layout`) + множество завершённых площадок.
  Сохраняется только то, что нельзя вывести из макета.

### Структура каталогов

```
src/
  app/                 Next.js: layout, page, стили
  game/
    data/              предметы, культуры, машины, площадки, макет мира, баланс
    engine/            Game, системы (игрок, сбор, передача, машины, работники,
                       площадки, грузовики, туториал), навигация A*, сохранения
    core/              математика, RNG, типы
  render/              R3F-компоненты: сцена, камера, модели, instancing, эффекты
  ui/                  HUD, джойстик, панели, модалки, всплывающие тексты
  audio/               синтез звуков
tests/                 юнит-тесты и бот-симуляция баланса
```

### Фаза 10 — Времена года ✅
Год из четырёх сезонов, каждый длится два игровых дня (20 минут), полный год — 80 минут.
Новая ферма начинается весной. Сезон сменяется ночью, поэтому мир меняется плавно, пока
все спят: утром — первый снег или первые жёлтые листья. Как и ночь, сезон даёт **только
бонус** — и свой сезонный спрос на рынке.

| Сезон | Бонус | Спрос ×1.5 |
|---|---|---|
| 🌸 Весна | посадки растут на 25% быстрее | яйца, мёд (+ варенье) |
| ☀️ Лето | работники бегают на 15% быстрее | сок, молоко (+ мороженое) |
| 🍂 Осень | каждый 4-й сбор — двойной | соус, сыр (+ тыквенный пирог) |
| ❄️ Зима | машины работают на 20% быстрее | хлеб, консервы, свитер |

В скобках — товары новых северных участков (фазы 12–14).

- [x] Календарь в движке: сезон, день сезона, год; событие смены сезона; плавный визуальный
      переход в ночь смены
- [x] Престиж «Новый сезон» переименован в «Новое поколение» (вкладка «Наследие»), сейв v2 с миграцией
- [x] Сезонный шейдер для всего мира: снег ложится на верхние грани (крыши, земля, заборы, кроны),

- [x] Небо, туман и земля по сезонам; зимой пруд замерзает: лёд, лунки на рыбных местах, утки улетают
- [x] Сезонные частицы: лепестки весной, пух летом, листья осенью, снежинки зимой
- [x] Бонусы сезонов и сезонный спрос (цены, заказы, грузовики); табличка спроса у рынка
- [x] HUD: значок сезона, карточка сезона по тапу (бонус, спрос, сколько осталось), тост при смене;

### Фаза 20 — «Между делом»: события и находки ✅

- [x] ✨ Золотые посадки: раз в 3.5–5.5 минуты одно растение, дерево или рыбное место на купленном

- [x] 🛒 Заезжий торговец: тележка с полосатым навесом и табличкой «5/7 · ⏳2:02» у края одного из

- [x] 📖 Альбом находок: 11 наборов по три редкости, шанс 1/110 при каждом сборе фермером; полный

## 4. Риски и решения

| Риск | Решение |
|---|---|
| Сотни растений и предметов тормозят | InstancedMesh на каждый тип, один материал с vertex colors |

## 5. Журнал решений

Что выяснилось по ходу реализации и почему сделано именно так.

| Решение | Почему |
|---|---|
| Площадка берёт деньги, только если игрок **остановился** на ней | Бот-симуляция показала: путь к рынку проходит через площадку улучшения рынка, и деньги незаметно «утекали» в неё — за 4 часа бот так и не накопил на второй участок |
| Стопка раскладывается на столбики по ~14 предметов (до 6) | При прокачанной вместимости работники носили башни по 9 м |
| Статический батчинг (`StaticBatch`) | Каждая деталь зданий и персонажей была отдельным мешем: 1334 draw call → 415 |
| Середина игры (Пастбище) подешевела, молоко и сыр подорожали | Отрезок Пастбище → Склад занимал 32 минуты против 15 у соседних |
| Сырьё нельзя продать | Иначе переработка необязательна, а цепочки — главный смысл игры |
| Мир = макет + множество купленных площадок | Сохранение маленькое и устойчивое к изменениям макета |
| Пруд и пасека — после Кондитерской, статуя — в самом конце | Ранняя и средняя игра уже выверены ботом; новые зоны продлевают финал, а не ломают середину |
| Рыба — «водная» культура с точкой стояния | Механика сбора та же (подошёл — собрал), но вода непроходима: у каждого места своя точка на берегу или причале |
| Лес на участке пасеки — «заросли», вырубаемые покупкой | Покупка участка ощущается как событие: деревья уходят в землю, летят листья |
| Статуя подешевела с $10M до $6M | Бот 17 минут копил на неё, ничего не покупая |
| Сутки — ускоренные 10 минут, а не реальные часы | По реальным часам вечерние игроки всегда видели бы ночь; так за сессию видна вся смена |
| Ночь синяя и неглубокая, площадки и HUD не затемняются | Атмосфера не должна мешать читаемости; ещё есть выключатель в настройках |
| Единственный игровой эффект ночи — рыба клюёт вдвое чаще | Только бонус, без штрафов: ночь не должна тормозить idle-прогресс |
| Престиж «Новый сезон» стал «Новым поколением» | «Сезон» теперь — время года; сейв v2 сам переименовывает поля старых сохранений |
| У каждого сезона только бонус и сезонный спрос | Как с ночью: idle-прогресс не тормозится. Бот проходит игру на 8% быстрее (2 ч 24 мин) |
| Сезонный вид — в шейдере общих материалов | Снег по нормали, листва по «зелёности» цвета: ни одна модель не дублируется, а персонажи, товары и посадки просто не подписаны на эффект |
| Случайность в шейдере — только по `flat`-варингам | Хэш от интерполированного сида давал попиксельную рябь: крошечные ошибки последних битов взрываются в `sin(x)·43758` |
| Сезон меняется в полночь, перекраска — ~1.5 минуты ночи | Утро встречает уже снегом или листопадом, а сама смена не бросается в глаза |
| Погода — по номеру дня, без сохранения | Детерминированно: после перезагрузки тот же дождь в то же время; тестируется распределением по тысячам дней |
| Радуга стоит перед камерой, а не на горизонте | Камера смотрит круто вниз — горизонта в кадре нет; дуга в плоскости обзора читается как радуга |
| Туман лёгкий (дальность 15–58 м) | Первая версия прятала площадки — правило «атмосфера не мешает читаемости» |
| Северный ряд — после Пасеки, статуя снова в конце | Как и с прудом и пасекой: выверенные начало и середина не трогаются, новый контент продлевает финал |
| Мороженое и пироги берут сырьё из старых зон (молоко из коровника, муку со второй мельницы) | Длинные маршруты грузчиков связывают карту в одну империю и делают прокачку старых машин снова полезной |
| Статуя подорожала до $150M | С тремя новыми зонами доход к финалу вырос до ~$700K/с; при $80M статуя покупалась почти сразу |
| Ярмарка ждёт, пока игрок закончит начатый заказ | Отнимать почти собранный заказ обидно; пустой заказ ярмарка заменяет сразу |
| Украшения сменяются целиком, а не плавно | Наборы переключаются ночью, в момент смены сезона — плавная анимация там всё равно не видна |
| Достижения и шляпа — общие для всех поколений | Престиж не должен отнимать трофеи; гардероб — постоянная награда |
| Шляпы с «фиксированной» палитрой, а не цветом игрока | Корона, цилиндр, тыква узнаются по цвету; персонаж перестраивается при смене шляпы (запечённый меш) |
| Перенос сохранения — кодом и файлом, без сервера | Облако требует бэкенда и аккаунтов; код в буфере обмена закрывает «другой браузер / телефон» уже сейчас |
| Код сжат (deflate) и подписан контрольной суммой | Короче в разы (небольшая ферма — ~600 символов), а обрезанный при копировании код не загрузит полфермы |
| Сохраняет только вкладка с «замком» | Две вкладки по очереди затирали прогресс друг друга каждые 5 секунд |
| Импорт и восстановление ставят сейву время «сейчас» | Иначе загрузка старого кода давала бы офлайн-доход за время, пока он лежал в файле |
| Звёзды — валюта лавки, а не автоматические +10% | После северных земель старая формула давала ×13 к ценам; выбор улучшений интереснее одного множителя |
| Делитель звёзд 1 млн, слава +15% за уровень | С 2.5 млн и +10% второе поколение было лишь на 14% быстрее — наследство не ощущалось |
| Бот покупает по «полезности на звезду», а не самое дешёвое | Самое дешёвое размазывало звёзды по офлайн-доходу, бесполезному для бота, и занижало эффект лавки |
| Звёзд за поколение примерно поровну (~38) | Статуя и площадки стоят одинаково, поэтому к финалу заработано столько же; отдача от лавки убывает с ценами — длинный хвост на десяток поколений |
| Награды событий — в секундах автоматического дохода, но не меньше «охапки» лучшего товара | Одно правило годится и на первой минуте, и при доходе $700K/с; до первых работников награда тоже ощутима |
| Золотое растение подбирается касанием, даже с полными руками | Иначе игрок бежит через всю карту и упирается в «МАКС» |
| «Золотая лихорадка» не трогает награду заказа | Заказ, созданный во время лихорадки, навсегда стоил бы вдвое больше |
| У событий свой генератор случайности, его состояние — в сейве | Тесты воспроизводят события, а перезагрузкой нельзя «перебросить кубик» |
| Тележка торговца — настоящее препятствие на выверенных местах | Места проверяет тест раскладки: тележка не встаёт на поля, площадки и проходы и не запирает работников |
| Беглец бежит на 78% скорости фермера и зигзагом | Поймать можно всегда, но не мгновенно: погоня на несколько секунд, а угол или забор помогают |
| Находки — только при сборе самим фермером | Поздние участки обслуживают работники; альбом — повод самому пройтись по полям |
| Стрелки у края — DOM-элементы HUD, которые двигает 3D-сцена | Ни одного React-рендера за кадр: HUD владеет элементами, сцена меняет только `transform` |
