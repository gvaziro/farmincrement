# Tiny Farm Empire — дорожная карта

> Idle Arcade Tycoon про уютную low-poly ферму. Next.js + React Three Fiber.
> Детальный дизайн механик и чисел — в [docs/GDD.md](docs/GDD.md).

## 1. Видение

Игрок бегает маленьким фермером по красочной миниатюрной ферме, собирает урожай
в огромную стопку за спиной, загружает машины, продаёт продукцию и шаг за шагом
превращает пустой участок в шумный автоматизированный комплекс.

### Столпы дизайна

1. **Всё происходит на карте.** Покупка — это площадка на земле, на которую нужно
   встать. Улучшение машины — площадка рядом с машиной. Меню — только там, где без
   него никак (прокачка фермера в доме, настройки).
2. **Каждое действие приятно.** Растения пружинят, предметы летят по дуге, стопка
   качается, монеты звенят, здания вырастают из земли с подскоком.
3. **Видимый рост.** Ферма с каждой покупкой становится шире, плотнее и оживлённее:
   больше полей, машин, работников, животных и грузовиков.
4. **Ручной труд → автоматизация.** Сначала всё делает игрок; потом каждый ручной
   процесс можно поручить работнику — и смотреть, как он работает.
5. **Простота.** Никакой сложной стратегии. Понятно с первой секунды без текста.

## 2. Технологии и архитектура

| Слой | Решение | Почему |
|---|---|---|
| Фреймворк | Next.js 16 (App Router), TypeScript | требование; одна страница, клиентский рендер игры |
| 3D | three.js 0.186 + @react-three/fiber 9 | декларативная сцена + полный доступ к three |
| Состояние UI | Zustand 5 | лёгкий стор для HUD, без лишних ререндеров |
| Логика | чистый TypeScript-движок `src/game` | тестируемо, не зависит от React, можно гонять бота-симулятора |
| Ассеты | процедурные low-poly модели из примитивов, канвас-текстуры | ноль внешних файлов, мгновенная загрузка |
| Звук | синтез через WebAudio | ноль файлов, мгновенный отклик |
| Тесты | Vitest | юнит-тесты движка + бот-симуляция баланса |
| Сохранения | localStorage + версия + миграции | офлайн-прогресс, автосейв |

### Поток данных

```
 Ввод (клавиатура / джойстик)
        │
        ▼
 Game (src/game/engine) ── tick(dt) в useFrame ──► мутирует GameState
        │                                            │
        │ события (продажа, покупка, звук, тост)     │ читается каждый кадр
        ▼                                            ▼
 EventBus ─► audio / UI-store (Zustand)        R3F-рендереры (refs, instancing)
```

* Горячий цикл (позиции, стопки, рост растений) **не проходит через React** —
  рендереры читают состояние движка в `useFrame` и пишут матрицы инстансов.
* React перерисовывает сцену только при структурных изменениях (открыта постройка,
  нанят работник) — через счётчик `structureVersion`.
* Мир = статичный макет (`data/layout`) + множество завершённых площадок.
  Сохраняется только то, что нельзя вывести из макета.

### Структура каталогов

```
src/
  app/                 Next.js: layout, page, стили
  game/
    data/              предметы, культуры, машины, площадки, макет мира, баланс
    engine/            Game, системы (игрок, сбор, передача, машины, работники,
                       площадки, грузовики, туториал), навигация A*, сохранения
    core/              математика, RNG, типы
  render/              R3F-компоненты: сцена, камера, модели, instancing, эффекты
  ui/                  HUD, джойстик, панели, модалки, всплывающие тексты
  audio/               синтез звуков
tests/                 юнит-тесты и бот-симуляция баланса
```

## 4. Риски и решения

| Риск | Решение |
|---|---|
| Сотни растений и предметов тормозят | InstancedMesh на каждый тип, один материал с vertex colors |
| React-ререндеры в горячем цикле | Состояние движка мутируется вне React, рендереры читают в `useFrame` |
| Работники застревают | A* по сетке 0.5 м, сглаживание, перестроение при новых зданиях, тайм-ауты |
| Баланс «на глаз» | Бот-симуляция по реальному движку, таймлайн покупок |
| Потеря прогресса | Автосейв раз в 5 с + при скрытии вкладки; версия схемы и миграции |
| Текст в 3D | Канвас-текстуры для площадок (без загрузки шрифтов из CDN) |

## 5. Журнал решений

Что выяснилось по ходу реализации и почему сделано именно так.

| Решение | Почему |
|---|---|
| Площадка берёт деньги, только если игрок **остановился** на ней | Бот-симуляция показала: путь к рынку проходит через площадку улучшения рынка, и деньги незаметно «утекали» в неё — за 4 часа бот так и не накопил на второй участок |
| Стопка раскладывается на столбики по ~14 предметов (до 6) | При прокачанной вместимости работники носили башни по 9 м |
| Статический батчинг (`StaticBatch`) | Каждая деталь зданий и персонажей была отдельным мешем: 1334 draw call → 415 |
| Середина игры (Пастбище) подешевела, молоко и сыр подорожали | Отрезок Пастбище → Склад занимал 32 минуты против 15 у соседних |
| Сырьё нельзя продать | Иначе переработка необязательна, а цепочки — главный смысл игры |
| Мир = макет + множество купленных площадок | Сохранение маленькое и устойчивое к изменениям макета |
| Пруд и пасека — после Кондитерской, статуя — в самом конце | Ранняя и средняя игра уже выверены ботом; новые зоны продлевают финал, а не ломают середину |
| Рыба — «водная» культура с точкой стояния | Механика сбора та же (подошёл — собрал), но вода непроходима: у каждого места своя точка на берегу или причале |
| Лес на участке пасеки — «заросли», вырубаемые покупкой | Покупка участка ощущается как событие: деревья уходят в землю, летят листья |
| Статуя подешевела с $10M до $6M | Бот 17 минут копил на неё, ничего не покупая |

## 6. Что дальше

Ближайшие шаги — из бэклога: смена дня и ночи, достижения,
service worker для игры без сети. Перед каждым изменением цен — `npm run balance`.

### Исправлено по итогам код-ревью

| Находка | Исправление |
|---|---|
| Груз грузовика, который ещё грузится, терялся при перезагрузке | При сохранении неоплаченный груз возвращается на склад |
| Округление при сохранении могло сделать площадку «переплаченной» и вечной | Оплата сохраняется с округлением вниз; переплаченная площадка сразу достраивается |
| Тупик: полная стопка сырья у забитой машины без денег | Игрок может переполнить вход ×1.5; компостный ящик у дома |
| Закрытие скрытой вкладки не давало офлайн-дохода за время скрытия | Время сохранения = момент скрытия вкладки |
| Незавершённый цикл машины терялся при перезагрузке | Прогресс цикла сохраняется |
| Битое значение туториала в сейве ломало каждый запуск | Валидация + резервная копия сейва и чистый старт |
| Сейв новой версии перезаписывался старой | Резервная копия перед стартом с нуля |
| Работник мог бесконечно перепланировать недостижимый путь | После 6 с блокировки — «прыжок» к цели |
| `formatMoney` срезал нули у целых: «450K» → «45K», «200K» → «2K» | Нули отбрасываются только в дробной части; тест на форматирование |
| Долгие тесты-симуляции иногда падали по таймауту под нагрузкой | Таймаут тестов поднят до 30 с |
