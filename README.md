# 🌾 Tiny Farm Empire

Уютная 3D idle-аркада про ферму: бегай маленьким фермером, собирай урожай в огромную
стопку за спиной, загружай машины, продавай товары и превращай пустой участок
в автоматизированную империю.

**Стек:** Next.js 16 · React 19 · React Three Fiber · three.js · Zustand · Vitest.
Все модели — процедурный low-poly, все звуки и музыка — синтез WebAudio: ни одного файла-ассета.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:3000.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер |
| `npm run build` / `npm start` | production-сборка и запуск |
| `npm test` | юнит-тесты движка |
| `npm run balance` | бот-симуляция баланса → `docs/balance-report.md` |
| `npm run lint` / `npm run typecheck` | ESLint / TypeScript |

## Управление

* **WASD / стрелки** — бег.
* **Зажать и тянуть** мышью или пальцем в любом месте — виртуальный джойстик.
* **Колесо / щипок / `+` `−`** — приближение камеры.
* **M** — звук вкл/выкл, **F** — полный экран, **Esc** — закрыть окно.
* Все действия — по зонам: встал на поле — собираешь, встал на паллету — грузишь,
  остановился на площадке с ценой — покупаешь.

## Что внутри

* 12 участков земли (карта 3×4), 20 машин, 13 производственных цепочек:
  пшеница → мука → хлеб · кукуруза → корм → яйца · трава → молоко → сыр ·
  яблоки → сок · помидоры → соус · мука + молоко + яйца → торт ·
  рыба → копчёная рыба → консервы · цветы → соты → мёд ·
  трава → шерсть → пряжа → свитер · клубника → варенье · молоко + клубника → мороженое ·
  тыква + мука → тыквенный пирог · тыква → фонарь.
* Пруд с причалом, утками и рыбалкой с берега; пасека на лесной поляне с пчёлами;
  овчарня с пушистыми овцами, прялкой и вязальней; ягодник с кафе-мороженым;
  тыквенное поле с пекарней и мастерской фонарей. Финал — Золотая статуя (~3.5 часа).
* Работники: сборщики, рыбаки, грузчики, операторы; путь — A* по навигационной сетке.
* Склад и грузовики доставки (×1.5 к цене), покупатели у рынка, доска заказов с бонусом.
* Компостный ящик у дома — выбросить ненужное; иконки товаров рендерятся из самих 3D-моделей.
* Прокачка фермера, работников, машин, рынка и грузовиков.
* Смена дня и ночи (10-минутные сутки): закаты, фонари, светлячки, сверчки; ночью рыба клюёт лучше.
* Времена года (год — 80 минут): цветущие деревья, листопад, снег и замёрзший пруд;
  у каждого сезона свой бонус и сезонный спрос на рынке.
* Погода: дожди (урожай растёт быстрее) с радугой, утренние туманы, снегопады.
* Сезонные праздники: украшения у дома и рынка, ёлка и снеговик зимой, ярмарка
  в последний день сезона с двойной наградой; шарфы и шапки в холода.
* 31 достижение и гардероб из 11 шляп (ковбойская, корона, цилиндр, тыква…).
* Туториал, подсказка «следующая цель», офлайн-доход, автосейв.
* «Новое поколение» (престиж) и лавка наследия: 9 семейных улучшений за звёзды —
  каждое поколение проходит ферму быстрее (бот: 3 ч 35 мин → 2 ч 10 мин → 1 ч 53 мин).
* Сохранения: перенос кодом одной строкой или файлом, резервные копии с восстановлением,
  защита от игры в двух вкладках; громкость, полный экран, «Что нового».

## Структура

```
src/
  app/          Next.js: layout, страница, стили HUD
  game/         чистый TypeScript-движок (без React/three): данные, системы, сохранения
  render/       R3F-сцена: модели, instancing, эффекты, площадки, камера
  ui/           HUD, джойстик, панели и модалки
  audio/        синтез звуков и генеративная музыка
  runtime/      связка движка с React: цикл, события, автосейв, Zustand-стор
tests/          юнит-тесты, бот для баланса
```

В режиме разработки движок доступен из консоли браузера: `window.__tfe.game.state`.
